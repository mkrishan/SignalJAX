# Selected references represented in the software map

The registry and documentation refer to the following work while preserving differences among the
paradigms:

- Manish Krishan Lal. *Backpropagation from KL Projections: Differential and Exact I-Projection
  Correspondences*. [arXiv:2512.24335](https://arxiv.org/abs/2512.24335), 2025.
- John MacLaren Walsh and Phillip A. Regalia. “Belief Propagation, Dykstra's Algorithm, and Iterated
  Information Projections.” *IEEE Transactions on Information Theory* 56(8), 2010.
- Adnan Darwiche. “A Differential Approach to Inference in Bayesian Networks.” *JACM* 50(3), 2003.
- Frederik Eaton. *Belief Propagation Generalizes Backpropagation*.
  [arXiv:2210.00610](https://arxiv.org/abs/2210.00610), 2020.
- Samuel S. Schoenholz et al. “Deep Information Propagation.” ICLR, 2017.
- M. Emtiyaz Khan and Håvard Rue. “The Bayesian Learning Rule.” *JMLR* 24, 2023.
- James C. R. Whittington and Rafal Bogacz. “An Approximation of the Error Backpropagation
  Algorithm in a Predictive Coding Network with Local Hebbian Synaptic Plasticity.” *Neural
  Computation* 29(5), 2017.
- Dong-Hyun Lee et al. “Difference Target Propagation.” ECML PKDD, 2015.
- Timothy P. Lillicrap et al. “Random Synaptic Feedback Weights Support Error Backpropagation for
  Deep Learning.” *Nature Communications* 7, 2016.
- Şenöz et al. “Variational Message Passing and Local Constraint Manipulation.” *Entropy* 23(7),
  2021, DOI 10.3390/e23070807.
