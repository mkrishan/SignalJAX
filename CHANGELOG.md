# Changelog

## 0.2.0 - 2026-08-30

- Expanded the NeurIPS-named package into the full cross-paradigm signal-study platform.
- Added composable finite operators, JVP comparisons, and fixed-point diagnostics.
- Added signal amplification/attenuation analysis across arbitrary readouts and granularities.
- Added cyclic projection dynamics and the Euclidean projection-residual corollary.
- Added an explicit claim-aware registry for established, restricted, corollary, diagnostic, and
  interface-only paradigm connections.
- Added scalar Gaussian projection-versus-differential trajectories and reviewer-driven examples.
- Distinguished the NeurIPS software name from the current arXiv paper title.

- Added complete/decomposable SPN upward-downward marginal and gate readouts.
